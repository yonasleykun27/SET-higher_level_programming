# 0x12. JavaScript - Warm up

## Description
This project is an introduction to JavaScript programming, covering basic syntax, variables, constants, conditional statements, command line arguments, loops, functions, objects, and script execution using Node.js.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- All scripts are interpreted on Ubuntu 20.04 LTS using `node` (version 14.x)
- All files end with a new line
- The first line of all files is exactly `#!/usr/bin/node` (except `100-let_me_const.js`)
- Code is compliant with `semistandard` (version 16.x.x)
- `var` is not used anywhere (`let` or `const` only)
- All files are executable

## Tasks

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Script that prints "JavaScript is amazing" using a constant variable `myVar` and `console.log` |
| `1-multi_languages.js` | Script that prints 3 lines: "C is fun", "Python is cool", and "JavaScript is amazing" |
| `2-arguments.js` | Script that prints a message depending on the number of arguments passed (`process.argv`) |
| `3-value_argument.js` | Script that prints the first argument passed to it without using `length` |
| `4-concat.js` | Script that prints two arguments in the format: `<first argument> is <second argument>` |
| `5-to_integer.js` | Script that prints `My number: <first argument converted in integer>` if convertible, else `Not a number` |
| `6-multi_languages_loop.js` | Script that prints 3 lines using an array of strings and a loop without using `if/else` and only one `console.log` |
| `7-multi_c.js` | Script that prints `x` times "C is fun" using a loop and at most two `console.log` calls |
| `8-square.js` | Script that prints a square of character `X` of given size using a loop |
| `9-add.js` | Script that prints the addition of 2 integers using the function prototype `function add(a, b)` |
| `10-factorial.js` | Script that computes and prints a factorial recursively |
| `11-second_biggest.js` | Script that searches the second biggest integer in the list of arguments |
| `12-object.js` | Script that updates an object's property value from 12 to 89 |
| `13-add.js` | Module that exports a function `add(a, b)` returning the addition of 2 integers |
| `100-let_me_const.js` | File that modifies the value of `myVar` to 333 |
| `101-call_me_moby.js` | Module that exports a function `callMeMoby(x, theFunction)` that executes a function `x` times |
| `102-add_me_maybe.js` | Module that exports a function `addMeMaybe(number, theFunction)` that increments and calls a function |
| `103-object_fct.js` | Script that adds a new function `incr` to an object that increments its integer value |
