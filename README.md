## Overview

This repository contains all projects, exercises, and assignments for **SE 300: High Level Programming II**. The curriculum focuses on mastering higher-level programming paradigms, foundational web technologies, and backend script execution, beginning with JavaScript and the Node.js runtime environment.

Key learning goals include:
- Understanding JavaScript language fundamentals, type coercion, scope, and closures.
- Utilizing modern ECMAScript standards (`let`, `const`, arrow functions, template literals).
- Processing command-line arguments using `process.argv`.
- Implementing modular code through CommonJS module exports and imports.
- Building, traversing, and manipulating JavaScript objects and function prototypes.
- Adhering to strict code quality standards using `semistandard`.

## Technical Requirements & Guidelines

- **Operating System**: Ubuntu 20.04 LTS
- **Runtime Environment**: Node.js (version 14.x)
- **Allowed Editors**: `vi`, `vim`, `emacs`
- **Coding Style**: Compliant with `semistandard` (version 16.x.x)
- **File Structure & Standards**:
  - All script files must be executable (`chmod +x <filename>`).
  - All files must end with a new line.
  - The first line of all scripts must be exactly `#!/usr/bin/node` (except where modifying existing non-script modules).
  - Variable declarations must strictly use `let` or `const` (the `var` keyword is prohibited).
